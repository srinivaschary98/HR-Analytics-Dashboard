# HR Analytics Dashboard

## Project Overview
This project analyzes employee attrition using the IBM HR Analytics dataset.

## Tools
- MySQL
- Tableau Public
- SQL
- Excel

## KPIs
- Total Employees
- Attrition Rate
- Employees Left
- Average Salary
- Average Age

## Dashboard Insights
- Sales department has the highest attrition.
- Employees working overtime are more likely to leave.
- Lower-income employees have higher attrition.
- Certain job roles experience higher turnover.

## Skills Demonstrated
- SQL Queries
- Data Cleaning
- KPI Creation
- Dashboard Design
- Data Visualization
- Business Insights
